# 3.6.1 Instruction format for supervised fine-tuning

Encoder-based models like BERT consume a raw text sequence and produce a classification or span label, so the “task format” is implicit in the model architecture and loss function. Decoder-based generative models—Llama, Mistral, Falcon, and their derivatives—work differently: they generate free-form text token by token, and the model must be told, explicitly within the input, what task it is being asked to perform. This is done through a structured **instruction format** sometimes called a “chat template” or “prompt template,” which wraps every training and inference example in a consistent set of *roles*.

The three canonical roles are:

+   • System: A fixed preamble that describes the model's persona, capabilities, and constraints. In financial applications this is where compliance-relevant instructions live—for example, “You are a financial analyst assistant. Always include appropriate disclaimers for forward-looking statements.”
+   • User: The input turn containing the instruction or question.
+   • Assistant: The model's response, which is the only part supervised during fine-tuning. The loss is computed on assistant tokens only; system and user tokens are masked.

A concrete financial instruction example looks as follows:

```
<|system|>
You are a financial analyst assistant. Classify the sentiment of
the following financial text as Positive, Negative, or Neutral.
Provide only the label and a one-sentence justification.
<|user|>
"The company raised its full-year revenue guidance by 8 percent,
citing stronger-than-expected demand in enterprise software."
<|assistant|>
Positive. The guidance raise signals management confidence in
sustained demand, a bullish indicator for the stock.
```

The specific delimiter tokens (<|system|>, <|user|>, <|assistant|>) vary by model family—Llama 3 uses <|start_header_id|>system<|end_header_id|>, Mistral uses [INST]/[/INST], and so on—but the three-role structure is universal. When fine-tuning with the Hugging Face transformers library, the `apply_chat_template` method handles delimiter insertion automatically:

```
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("meta-llama/Meta-Llama-3-8B-Instruct")

messages = [
    {"role": "system", "content": "You are a financial analyst assistant..."},
    {"role": "user",
     "content": "Classify sentiment: 'Revenue declined 12%...'"},
    {"role": "assistant", "content": "Negative. A 12% revenue decline ..."},
]
```
