We begin with hardware architecture because accelerator choice, memory capacity, deployment location, and latency requirements shape many of the infrastructure decisions that follow.

# 10.1 Hardware architecture for financial LLMs

Hardware choices strongly influence cost, latency, throughput, and operational flexibility. The appropriate platform depends on whether the dominant workload is pre-training, fine-tuning, batch embedding, high-concurrency generation, low-latency classification, retrieval, or a combination of these tasks. Peak floating-point throughput alone is therefore an inadequate selection criterion.

Memory capacity and bandwidth, interconnect topology, supported numerical formats, serving software, availability, power density, and the ability to operate in the required jurisdiction can be equally important.
