# 4.8.1 System architecture

The class below wires up an embedding function, a vector collection, a retrieval method, and a generation method that together implement the online half of the pipeline. The constructor configures the vector store and the embedding model; `add_documents` handles indexing; `retrieve` performs similarity search with optional metadata filtering; `generate_response` formats the retrieved passages into a grounded prompt and calls the LLM with a system message that requests citation behavior; and `query` composes these into the end-to-end RAG call that user-facing code is expected to invoke. Prompt instructions are useful guardrails, but they are not compliance controls by themselves; production systems still need deterministic permission checks, output validation, and human escalation paths.
