
## 1.6.1 Multi-head self-attention

Multi-head self-attention enables each token in a sequence to selectively aggregate information from all other tokens, conditioned on different learned notions of relevance. This mechanism is built upon three learned linear projections of the input representations: _queries_, _keys_, and _values_. Queries (_Q_) determine which information a token seeks, keys (_K_) encode how each token should be matched, and values (_V_) carry the content to be aggregated.

Formally, given input matrices _Q_, _K_, and _V_ derived from the same sequence in the self-attention setting, multi-head attention applies _h_ parallel attention operations, each operating in a distinct learned subspace. The outputs of these attention heads are concatenated and linearly transformed to produce the final representation:

\(\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W_o.\) (1.6)

Each attention head is computed by first projecting the inputs into head-specific query, key, and value spaces, followed by scaled dot-product attention:

\(\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V).\) (1.7)

The projection matrices \(W_i^Q\), \(W_i^K\), and \(W_i^V\) allow each head to focus on different relational patterns, such as syntactic dependencies, semantic similarity, or long-range interactions. By attending to multiple representation subspaces in parallel, multi-head attention significantly enhances the expressive capacity of the model compared to a single-head mechanism, while preserving computational efficiency through dimensionality reduction within each head [Vaswani et al., 2017].

## 1.6.2 Positional encoding

Self-attention is permutation-invariant. This means that given a set of token embeddings, the attention mechanism alone cannot distinguish whether a token appears at the beginning or the end of a sequence. To recover order information, positional encodings inject explicit position-dependent signals into the input representations.

Let \(x_t \in \mathbb{R}^{d_\text{model}}\) denote the embedding of the token at position _t_. Positional encodings add a deterministic vector \(p_t \in \mathbb{R}^{d_\text{model}}\) so that the input to the first Transformer layer becomes

\(\tilde{x}_t = x_t + p_t.\) (1.8)

In the original Transformer architecture, positional encodings are defined using sinusoidal functions:

\(p_t^{(2k)} = \sin\left(\frac{t}{10000^{2k/d_\text{model}}}\right),\) (1.9)
\(p_t^{(2k+1)} = \cos\left(\frac{t}{10000^{2k/d_\text{model}}}\right),\) (1.10)

for \( k = 0, \dots, d_{\text{model}}/2 - 1 \).

This construction assigns each position a unique representation while ensuring that relative positional offsets correspond to linear transformations in embedding space. As a consequence, the model can infer relative distances between tokens through dot products in attention, even though the encodings themselves are absolute. Since positional encodings are added before any attention operation, positional information propagates through all layers of the network.

## 1.6.3 Layer normalization and residual connections

Training deep Transformer stacks requires careful control of signal magnitudes and gradient flow. Two architectural components address these challenges: layer normalization and residual connections.

Layer normalization normalizes activations across feature dimensions for each token independently. Given a vector \( h \in \mathbb{R}^d \), layer normalization is defined as

\(\text{LN}(h) = \gamma \odot \frac{h - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta,\) (1.11)

where \(\mu = \frac{1}{d} \sum_{i=1}^d h_i\) and \(\sigma^2 = \frac{1}{d} \sum_{i=1}^d (h_i - \mu)^2\), and \(\gamma, \beta \in \mathbb{R}^d\) are learned affine parameters. Residual connections allow each sublayer to learn a perturbation of the identity mapping. For a generic sublayer \(\mathcal{F}(\cdot)\), the output is

\(h_{\text{out}} = h_{\text{in}} + \mathcal{F}(h_{\text{in}}).\) (1.12)

Combined with normalization, residual connections stabilize optimization by preserving information across layers and enabling gradients to propagate without vanishing. Empirically and theoretically, this design allows Transformers to scale to great depth while maintaining representational fidelity.

## 1.6.4 Feedforward neural networks

In addition to attention-based interactions across tokens, each Transformer layer contains a position-wise feedforward neural network (FFN). Unlike attention, which couples different sequence positions, the FFN operates independently on each token representation.

Formally, for an input vector \( x \in \mathbb{R}^{d_{\text{model}}} \), the FFN is defined as

\(\text{FFN}(x) = \phi(xW_1 + b_1)W_2 + b_2,\) (1.13)

where \( W_1 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}} \), \( W_2 \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}} \), and \(\phi(\cdot)\) is a nonlinear activation function such as ReLU or GeLU.

The intermediate expansion to dimension \( d_{\text{ff}} \gg d_{\text{model}} \) allows the model to perform rich nonlinear transformations before projecting back to the original embedding space. Intuitively, attention layers determine _what information to aggregate_, while feedforward networks determine _how that information is transformed locally_. This alternation between global interaction and local nonlinear processing is central to the expressive power of Transformer architectures.

## 1.7 Optimization objectives

The training objectives used for LLMs are fundamental to their success and directly impact their suitability for different financial applications. Understanding these objectives helps practitioners choose the right pre-trained model for their specific use case—whether they need bidirectional understanding for document analysis (MLM-trained models) or autoregressive generation for report writing (CLM-trained models). Additionally, newer alignment techniques like RLHF are crucial for ensuring model outputs meet the high standards of accuracy and reliability required in financial contexts. The success of LLMs derives from the design of their optimization objectives suited to their tasks.

In Masked Language Modeling (MLM) as used in models like BERT, the objective is to predict masked tokens using a cross-entropy loss:

$$\mathcal{L}_{\text{MLM}} = - \sum_{i \in \mathcal{M}} \log P(w_i|\text{context})$$ (1.14)

This compels the model to learn context-dependent representations [Devlin et al., 2019].

**Causal language modeling (CLM)**, as used in GPT and many recent models, trains the model to predict the next token:

$$\mathcal{L}_{\text{CLM}} = - \sum_{t=1}^{T} \log P(w_t|w_{<t})$$ (1.15)

This approach supports autoregressive generation, ensuring coherent and contextually appropriate text [Brown et al., 2020], [OpenAI, 2022].

Beyond supervised pre-training, reinforcement learning techniques, such as **Reinforcement Learning from Human Feedback (RLHF)** and newer methods like **Direct Preference Optimization (DPO)**, are employed to further align model outputs with human preferences or specific instructions.

The goal is often to optimize a reward signal $r(x)$ or directly optimize based on preference data for a generated sequence $x$:

$$\max_{\theta} \mathbb{E}_{x \sim \pi_{\theta}} [r(x)]$$ (1.16)

where $\pi_{\theta}$ is the language model's policy parameterized by $\theta$. These methodologies help refine model outputs to be more helpful, harmless, and honest, aligning them better with user expectations.

**Case study — Earnings call assistant:** Optimization objectives shape what the assistant can and cannot do reliably. The sentiment classifier uses an MLM-style objective during pre-training so it reads full context before assigning a tone score. The summary generator uses a CLM objective so it produces coherent multi-sentence outputs. RLHF is then applied to align the summary style with what analysts actually find useful—concise, action-oriented, and free of hallucinated figures.

## 1.8 Evolution of financial AI

Now that we have established the technical foundations of language models and their architectural components, we can examine how these advances have been specifically adapted to the financial sector. The evolution of AI in finance traces a clear progression from simple rule-based systems to the sophisticated LLMs of today. Early systems in the 1980s employed rule-based expert systems for credit scoring. Statistical quant models gained prominence in the 1990s, leveraging econometric techniques. Neural networks emerged in the 2000s, but only recently have Transformer-based models like FinBERT (2020) and BloombergGPT (2023) delivered real-time sentiment analysis and risk modeling.

### 1.8.1 Rule-based systems to neural networks

The evolution of AI in finance has progressed from classical rule-based expert systems to sophisticated statistical models and, ultimately, to deep neural networks. Early financial AI systems relied on explicitly programmed rules and heuristics; however, these approaches could not scale effectively with the increasing volume and complexity of financial data. The shift to data-driven methods allowed AI systems to recognize patterns from historical data, leveraging models such as RNNs and, more recently, the highly effective Transformer architectures [Vaswani et al., 2017].

### 1.8.2 Emergence of domain-specific financial AI models

Specialized models adapted to financial datasets continue to be developed. For example, FinBERT demonstrated the value of continuing BERT pre-training on financial communication and then fine-tuning on financial sentiment labels [Yang et al., 2020]. This is domain adaptation of representations and objectives; it should not be described as requiring a new tokenizer or a hand-built glossary. Similarly, BloombergGPT represented a significant effort to train a large model on a blended general and financial corpus [Wu et al., 2023b]. These efforts highlighted the benefits of combining general LLM capabilities with deep financial domain knowledge.
