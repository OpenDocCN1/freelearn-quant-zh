# 9.5 Advanced RL techniques for financial LLMs

Beyond standard policy-optimization methods, more advanced RL approaches can be used to model financial problems with multiple levels of decision-making or multiple interacting participants. Two examples are hierarchical reinforcement learning, which separates strategic and tactical decisions, and multi-agent reinforcement learning, which models interactions between different market participants.

# 9.5.1 Hierarchical reinforcement learning

Financial decision-making often involves multiple levels of planning. For example, a high-level strategy may define portfolio objectives or risk limits, while lower-level policies handle asset allocation, hedging, trade execution, or tax-aware adjustments.

The following illustrative example shows how a meta-controller can select a high-level financial goal and then delegate execution to a specialized sub-policy.

Listing 9.10: Hierarchical financial agent with meta-controller and sub-policies

```
class HierarchicalFinancialAgent:
    def __init__(self):
        self.meta_controller = MetaController()  # High-level strategy
        self.sub_policies = {
            'asset_allocation': AssetAllocationPolicy(),
            'risk_management': RiskManagementPolicy(),
            'trade_execution': TradeExecutionPolicy(),
            'tax_optimization': TaxOptimizationPolicy()
        }

    def hierarchical_decision_making(self, state):
        """
        Make decisions using hierarchical RL structure.
        """
        # Meta-controller selects high-level goal
        goal = self.meta_controller.select_goal(state)

        # Select appropriate sub-policy
        sub_policy = self.sub_policies[goal['type']]

        # Execute sub-policy until goal completion
        sub_trajectory = []
        sub_state = state

        while not self.is_goal_completed(goal, sub_state):
            action = sub_policy.select_action(sub_state, goal)
            next_state, reward, done = self.env.step(action)

            sub_trajectory.append((sub_state, action, reward))
            sub_state = next_state
```
