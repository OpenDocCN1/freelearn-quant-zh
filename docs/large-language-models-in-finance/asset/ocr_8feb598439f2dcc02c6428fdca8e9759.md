```
for agent in agents: # analyst, trader, risk_manager, ...
    prompt = build_agent_prompt(agent, state)
    action, score, log_prob = agent.propose_action(prompt)
    agent_outputs.append(
        {"action": action, "score": score, "role": agent.role,
         "log_prob": log_prob}
    )

final_action = aggregate_actions(agent_outputs, role_weights)
next_state, reward, done, info = env.step(final_action)

# store log-probs for all agents to shape their updates
traj_log_probs.append([out["log_prob"] for out in agent_outputs])
traj_rewards.append(reward)
state = next_state

# compute returns / advantages and update agents jointly
advantages = compute_advantages(traj_rewards, gamma, lam)
for agent_idx, agent in enumerate(agents):
    loss = 0.0
    for t, A_t in enumerate(advantages):
        loss -= traj_log_probs[t][agent_idx] * A_t
    agent.optimizer.zero_grad()
    loss.backward()
    agent.optimizer.step()
```

Again, this is a schematic pattern. Real systems require more nuanced reward shaping, coordination, tool access, audit logging, transaction-cost modeling, and safety checks before any live deployment.

# Reported empirical behavior

On a short out-of-sample period for a small set of large-cap equities, Xiao et al. [2025] found that the multi-agent system:

+   * Achieves cumulative returns above buy-and-hold and simple technical baselines;
+   * Exhibits high Sharpe ratios over the tested window, partly due to the absence of large drawdowns; and
+   * Benefits materially from the risk-manager agent, which reduces exposure around high-risk events.

The authors explicitly caution that the short horizon and unusually benign conditions limit the generality of these Sharpe estimates.
