# 3.6 Supervised fine-tuning

Supervised fine-tuning adapts models using labeled data for specific tasks. With the parameter-efficient strategies from the previous section in hand—LoRA or QLoRA to manage memory, a well-curated financial dataset, and a stable optimization setup—the next question is how to structure the training signal for different financial problems. This section walks through how supervised fine-tuning covers the most important task families: named entity recognition, question answering, and summarization. Each involves a different input-output format and calls for a different model architecture and loss function, but all share the same underlying fine-tuning workflow described earlier.
