+   - Text extraction and cleaning
+   - Chunking strategies (fixed-size, semantic, recursive)

**Stage 2: Query processing and retrieval** This stage takes a user query, brings it into the same representational space as the indexed chunks, and surfaces the small set of passages that should ground the answer. Its job is to maximize the probability that the relevant evidence is among the retrieved set.

+   - Query understanding and reformulation [Ma et al., 2023]
+   - Query embedding generation
+   - Similarity search (dense, sparse, hybrid)
+   - Re-ranking and filtering [Nogueira and Cho, 2019]
+   - Metadata filtering

**Stage 3: Context augmentation** This stage turns the retrieved passages into a well-structured prompt that the language model can actually use. It is responsible for fitting evidence into the context window without losing attribution.

+   - Retrieved document formatting
+   - Context window management
+   - Prompt construction
+   - Citation management

**Stage 4: Generation and post-processing** This stage produces the final answer conditioned on the augmented context and verifies that the answer is faithful to the retrieved evidence. It is the user-facing layer where grounding becomes auditable.

+   - LLM generation with augmented context
+   - Response extraction
+   - Citation attribution
+   - Answer verification
