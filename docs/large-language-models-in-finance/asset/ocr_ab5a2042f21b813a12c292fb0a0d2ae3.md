Consider a portfolio-monitoring example. A large predictive model may rank securities by expected return. A deployable agent must also maintain the portfolio's current exposures, identify which data were available at the decision time, retrieve mandate restrictions, generate alternative trades, estimate transaction costs and market impact, reject actions that violate limits, obtain approval for high-impact decisions, submit an order through a sandboxed interface, and compare realized execution with the plan. These requirements explain why architectural change is necessary beyond simply increasing model size.

# 14.2.1 Core components of an agentic architecture

An autonomous financial agent can be represented as a collection of interconnected modules whose authorities are explicitly separated.

Definition 14.2.1 (Autonomous financial agent). A bounded autonomous financial agent is a composite system

```
\mathfrak{A} = \langle \mathcal{R}, \mathcal{M}, \mathcal{P}, \mathcal{T}, \mathcal{L}, \mathcal{G} \rangle, \quad (14.1)
```

where:

+   - \(\mathcal{R}\) is the core reasoning or proposal engine;
+   - \(\mathcal{M}\) is the memory and belief-state system;
+   - \(\mathcal{P}\) is the planning and goal-decomposition module;
+   - \(\mathcal{T}\) is the typed tool-use and action interface;
+   - \(\mathcal{L}\) is the evaluation, reflection, and learning module; and
+   - \(\mathcal{G}\) is the governance layer containing permissions, risk limits, validation rules, approval requirements, and audit controls.

The agent is autonomous only within the admissible action set defined by \(\mathcal{G}\).

# The core reasoning engine

The core engine interprets a high-level objective, summarizes evidence, proposes intermediate steps, and produces structured candidate actions. It can be a dense model or, in some deployments, a Mixture-of-Experts (MoE) model [Fedus et al., 2022]. MoE architectures can be useful because sparse routing allows different experts to specialize in domains such as accounting language, legal clauses, market microstructure, code, or risk analysis while activating only a subset of parameters for each token. This can increase effective capacity without requiring every parameter to be evaluated on every step. The advantage is operational rather than magical: routing must be monitored, expert specialization can be uneven, and an MoE does not replace the external controls required for financial decisions.

```
\mathcal{R} : \mathcal{X} \times \mathcal{B} \times \mathcal{Q} \longrightarrow \mathcal{Z}, \quad (14.2)
```

where \(\mathcal{X}\) is the current observation space, \(\mathcal{B}\) is the belief state supplied by memory, \(\mathcal{Q}\) is the goal or query space, and \(\mathcal{Z}\) is a space of proposed plans or structured actions. The output is a proposal, not automatically an executable order.
