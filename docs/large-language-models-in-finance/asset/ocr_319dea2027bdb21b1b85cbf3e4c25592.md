# ## 9.3.1 Proximal policy optimization (PPO) for LLMs

Proximal policy optimization (PPO) is widely used in LLM alignment because it improves a model using reward feedback while limiting how far the updated policy can move from the earlier policy. This constraint helps prevent large policy updates that could make the model unstable or degrade previously learned behavior.

In simple terms, PPO compares the probability of an action under the old and new policies. If the update is too large, the clipped objective reduces the incentive for the model to move too far in one training step. This stability is especially important in financial applications, where small changes in model behavior can affect compliance, risk explanations, or decision-support outputs [Schulman et al., 2017, Ouyang et al., 2022].

A second control is the Kullback–Leibler (KL) divergence from a fixed reference policy. For a prompt _x_, it is

\( D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}}) = \mathbb{E}_{y \sim \pi_\theta(\cdot|x)} [\log \pi_\theta(y | x) - \log \pi_{\text{ref}}(y | x)] . \qquad (9.10) \)

A token-level average of current minus reference log probabilities on sampled responses is a Monte Carlo estimate of this quantity. Penalizing large KL divergence discourages the aligned policy from departing abruptly from the base model, although the coefficient must be tuned because an excessive penalty can suppress useful learning.
