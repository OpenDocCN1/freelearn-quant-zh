GPT employs a causal language modeling objective where the model predicts the next token given the previous tokens. Its training objective is given by:

```
$\mathcal{L}_{\text{GPT}} = - \sum_{t=1}^T \log P(w_t|w_1, \dots, w_{t-1})$ (1.3)
```

This unidirectional approach supports generative tasks such as text completion and creative writing [Brown et al., 2020], [OpenAI, 2022]. Successive generations continue to build on this principle.

# 1.5.2 BERT and its derivatives

BERT introduced masked language modeling, training on dual directions to capture bidirectional context. Successors such as RoBERTa and DeBERTa refined training regimes and data scale, enhancing performance on comprehension tasks.

BERT's innovations include:

+   - **Bidirectional training**: Sees both left and right context simultaneously
+   - **Masked language modeling**: Learns by predicting randomly masked tokens
+   - **Segment embeddings**: Can process pairs of sentences/documents
+   - **Pre-training objectives**: MLM and Next Sentence Prediction (later removed in RoBERTa)

BERT uses a masked language modeling (MLM) objective in which a percentage of tokens is masked, and the model predicts these tokens based on their context:

```
$\mathcal{L}_{\text{BERT}} = - \sum_{i \in \mathcal{M}} \log P(w_i|w_1, \dots, w_{i-1}, [\text{MASK}], w_{i+1}, \dots, w_T)$ (1.4)
```

where $\mathcal{M}$ represents the set of masked positions [Devlin et al., 2019]. While foundational, newer architectures often incorporate or evolve beyond pure MLM.

# 1.5.3 T5 and the text-to-text paradigm

T5 reframes diverse NLP tasks—translation, summarization, question answering—as text-to-text transformations, simplifying fine-tuning and promoting transfer across tasks.

T5's unified approach offers several advantages:

+   - **Task unification**: All tasks use the same model architecture and training procedure
+   - **Simplified deployment**: One model handles multiple tasks
+   - **Transfer learning**: Knowledge transfers between related tasks
+   - **Flexible prompting**: Task behavior controlled through input prefixes
