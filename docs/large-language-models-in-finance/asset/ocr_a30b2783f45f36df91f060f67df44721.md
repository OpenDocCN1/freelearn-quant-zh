for \( k = 0, \dots, d_{\text{model}}/2 - 1 \).

This construction assigns each position a unique representation while ensuring that relative positional offsets correspond to linear transformations in embedding space. As a consequence, the model can infer relative distances between tokens through dot products in attention, even though the encodings themselves are absolute. Since positional encodings are added before any attention operation, positional information propagates through all layers of the network.

# ## 1.6.3 Layer normalization and residual connections

Training deep Transformer stacks requires careful control of signal magnitudes and gradient flow. Two architectural components address these challenges: layer normalization and residual connections.

Layer normalization normalizes activations across feature dimensions for each token independently. Given a vector \( h \in \mathbb{R}^d \), layer normalization is defined as

\(\text{LN}(h) = \gamma \odot \frac{h - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta,\) (1.11)

where \(\mu = \frac{1}{d} \sum_{i=1}^d h_i\) and \(\sigma^2 = \frac{1}{d} \sum_{i=1}^d (h_i - \mu)^2\), and \(\gamma, \beta \in \mathbb{R}^d\) are learned affine parameters. Residual connections allow each sublayer to learn a perturbation of the identity mapping. For a generic sublayer \(\mathcal{F}(\cdot)\), the output is

\(h_{\text{out}} = h_{\text{in}} + \mathcal{F}(h_{\text{in}}).\) (1.12)

Combined with normalization, residual connections stabilize optimization by preserving information across layers and enabling gradients to propagate without vanishing. Empirically and theoretically, this design allows Transformers to scale to great depth while maintaining representational fidelity.

# ## 1.6.4 Feedforward neural networks

In addition to attention-based interactions across tokens, each Transformer layer contains a position-wise feedforward neural network (FFN). Unlike attention, which couples different sequence positions, the FFN operates independently on each token representation.

Formally, for an input vector \( x \in \mathbb{R}^{d_{\text{model}}} \), the FFN is defined as

\(\text{FFN}(x) = \phi(xW_1 + b_1)W_2 + b_2,\) (1.13)

where \( W_1 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}} \), \( W_2 \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}} \), and \(\phi(\cdot)\) is a nonlinear activation function such as ReLU or GeLU.

The intermediate expansion to dimension \( d_{\text{ff}} \gg d_{\text{model}} \) allows the model to perform rich nonlinear transformations before projecting back to the original embedding space. Intuitively, attention layers determine _what information to aggregate_, while feedforward networks determine _how that information is transformed locally_. This alternation between global interaction and local nonlinear processing is central to the expressive power of Transformer architectures.
