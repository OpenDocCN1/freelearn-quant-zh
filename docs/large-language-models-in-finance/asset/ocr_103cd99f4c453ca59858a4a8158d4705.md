The predict_with_generate=True flag instructs the trainer to use beam search during evaluation, which produces higher-quality summaries than greedy decoding and ensures that the evaluation metrics reflect what the model would actually output in deployment. Four beams (generation_num_beams=4) is a common default that balances output quality against evaluation speed.

# Evaluation metrics

Summarization is harder to evaluate automatically than classification or span extraction, because a good summary can use entirely different wording from the reference while conveying the same information. The three metrics below capture complementary aspects of summary quality:

+   * **ROUGE**: Overlap-based metrics (ROUGE-1, ROUGE-2, ROUGE-L)
+   * **BERTScore**: Semantic similarity using embeddings
+   * **Human Evaluation**: Factual accuracy, completeness, readability
