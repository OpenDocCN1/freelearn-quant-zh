# ## 12.1.1 BloombergGPT: Industry-scale financial specialization

At a basic level, BloombergGPT is an industry-scale financial LLM: a roughly 50-billion-parameter, decoder-only transformer trained on a large mixture of general text and financial data [Wu et al., 2023b]. Its purpose is not only to answer general-language prompts, but also to handle financial language such as filings, market news, entity names, earnings-call language, and research-style questions. It therefore provides a useful first example of how financial domain specialization changes both the data distribution and the training objective.

Let $\mathcal{D}_{\text{gen}}$ and $\mathcal{D}_{\text{fin}}$ denote general and financial corpora with token counts $N_{\text{gen}}$ and $N_{\text{fin}}$, respectively. A token is a discrete unit of text used by the model, and a sequence $x_{1:T} = (x_1, \dots, x_T)$ contains $T$ such tokens. For a GPT-style autoregressive model, causal language modeling (CLM) means training the model to predict the next token from the previous tokens. Training can therefore be represented by the objective

```
$$\mathcal{L}_{\text{CLM}}(\theta) = -\mathbb{E}_{(x_{1:T}, d) \sim \mathcal{D}} \sum_{t=1}^T \log p_\theta(x_t \mid x_{<t}, d), \quad (12.1)$$
```
