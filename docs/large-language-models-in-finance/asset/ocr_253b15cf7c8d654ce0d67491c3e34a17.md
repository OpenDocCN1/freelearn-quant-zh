which is not CQL: Q is a function of (s, a), and the conservative term is a log-sum-exp over actions *at each state in the batch*, minus the value the dataset's own action achieved at that same state. Averaging Q over a bag of sampled actions with the states thrown away penalizes nothing in particular.

Discrete action set below. For continuous actions, replace the exact log-sum-exp with the importance-sampled estimate of Kumar et al. """

```
def __init__(self, q_network, dataset, alpha=5.0, n_actions=None):
    self.q_network = q_network        # Q(s, .) -> [B, n_actions]
    self.dataset = dataset
    self.alpha = alpha
    self.n_actions = n_actions
def cql_loss(self, states, actions, rewards, next_states, dones):
    # 1. The ordinary TD / Bellman term.
    td_loss = self.standard_q_loss(
        states, actions, rewards, next_states, dones)
    # 2. The conservative term, evaluated AT EACH STATE.
    q_all = self.q_network(states)        # [B, n_actions]
    logsumexp_q = torch.logsumexp(q_all, dim=1)    # [B]
    q_data = q_all.gather(
        1, actions.unsqueeze(1)).squeeze(1)    # [B]
    # Push down the soft-max over ALL actions at s; hold up the
    # value of the action actually taken in the data at s.
    conservative = (logsumexp_q - q_data).mean()
return td_loss + self.alpha * conservative
```

# Constitutional AI for financial safety

Constitutional AI uses a set of written principles to critique, revise, and guide model outputs [Bai et al., 2022]. In financial contexts, these principles can reflect requirements such as risk disclosure, privacy protection, suitability, and avoidance of misleading or prohibited advice. The constitution is not itself a legal control: its principles must be versioned, tested against concrete policies, and paired with deterministic validation and human escalation.
