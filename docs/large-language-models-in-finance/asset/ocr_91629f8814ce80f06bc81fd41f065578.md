The official companion repository is Packt's official _LLMs in Finance_ repository. It is not intended to be a full production platform. A reference implementation is considered acceptable only if it satisfies the following checklist:

+   1. all externally visible objects have typed schemas;
+   2. timestamp checks are explicit and fail closed;
+   3. retrieval returns evidence identifiers, not anonymous text blobs;
+   4. material claims can be linked to evidence identifiers;
+   5. tool calls pass deterministic authorization before execution;
+   6. evaluation scripts compute both task metrics and governance metrics;
+   7. tests run without private credentials or proprietary data.
