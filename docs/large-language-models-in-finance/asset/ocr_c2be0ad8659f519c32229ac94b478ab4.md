Numerical tokenization strategies must balance preservation of numerical relationships with tokenization efficiency. Several approaches including the following have proven useful for financial applications:

+   - **Magnitude-cased tokenization**: Separate tokens for different numerical magnitudes (thousands, millions, billions)
+   - **Precision-aware tokenization**: Different treatment for whole numbers versus decimals
+   - **Financial format tokenization**: Specialized handling for percentages, currency amounts, ratios
+   - **Contextual numerical tokenization**: Different tokenization based on numerical context (prices vs. ratios vs. dates)

Scientific notation handling is particularly important in financial contexts involving very large values or precise percentage changes. The tokenization scheme must preserve the relationship between mantissa and exponent while enabling efficient model processing.

Financial documents also combine narrative explanation with tables, charts, and structured disclosures. Multi-modal tokenization approaches address this diversity by generating unified representations that preserve cross-modal relationships. This can be expressed as follows:

Token_unified = Concat(Token_text, Token_numerical, Token_structural) (2.32)

Finally, position encoding for financial data must reflect the structural complexity of financial documents. Unlike simple sequential text, financial reports contain hierarchical sections, table dependencies, and cross-references that carry analytical meaning. Positional encoding schemes must therefore account for more than linear token order if structural context is to be preserved.
