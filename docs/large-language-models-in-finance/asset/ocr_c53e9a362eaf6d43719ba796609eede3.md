If \(\widehat{\rho}_n(L_a)\) is an empirical CVaR estimate from \(n\) scenarios, a naive shield that admits \(a\) whenever \(\widehat{\rho}_n(L_a) \le B\) is vulnerable to optimistic underestimation. Under bounded losses and a declared empirical-CDF concentration model, a conservative DKW-style margin for the CVaR estimate can be written as

\(\epsilon(n, \eta) = \frac{M}{1 - \alpha} \sqrt{\frac{\log(1/\eta)}{2n}},\) (14.8)

_This is an illustrative conservative margin, not a proved finite-sample certificate._ A genuine certificate would have to fix the one- or two-sided DKW form, the i.i.d. or dependent scenario model, the empirical-CVaR estimator convention, the derivation from CDF sup-norm error to CVaR error, whether the bound holds simultaneously across candidate actions, and the confidence convention. None of those is supplied here, and until they are, the correct reading of the display below is a design heuristic that errs toward caution — useful as a shield, inadmissible as a guarantee.

**Where the margin goes matters, and it is easy to get backwards.** Suppose the gate admits whenever \(\widehat{\rho}_n(L_a) \le B\) and one then concludes, on the event that the concentration bound holds,

\(\rho(L_a) \le \widehat{\rho}_n(L_a) + \epsilon(n, \eta) \le B + \epsilon(n, \eta).\) (14.9)

This is a true statement, and it is _not_ budget compliance. It certifies a _relaxed_ budget \(B + \epsilon\): the admitted action may exceed the stated budget \(B\) by up to the margin, which is precisely the loosening the gate was built to prevent. A shield that reports “within budget” on the strength of (14.9) is reporting compliance with a budget nobody approved.

To certify the budget that was actually declared, the margin must be _reserved on the admission side_, not spent on the conclusion side. Admit \(a\) only if

\(\widehat{\rho}_n(L_a) + \epsilon(n, \eta) \le B,\) (14.10)

whereupon, on the same event, \(\rho(L_a) \le \widehat{\rho}_n(L_a) + \epsilon(n, \eta) \le B\) and the population budget holds. The two rules differ by exactly one \(\epsilon\), they look almost identical on the page, and only one of them enforces what it says.

The distinction deserves a name in any control document that uses it:

+   • **Budget compliance.** Admission requires \(\widehat{\rho}_n + \epsilon \le B\). Conclusion: \(\rho \le B\). Fewer actions pass; the ones that do respect the declared limit.

+   • **Bounded exceedance.** Admission requires \(\widehat{\rho}_n \le B\). Conclusion: \(\rho \le B + \epsilon\). More actions pass, and the effective limit is \(B + \epsilon\), which must then be the number written in the risk mandate.

Either is defensible. Choosing one and reporting the other is not, and the failure is silent: the gate returns `ADMIT`, the log records “within budget,” and the limit that was actually enforced appears nowhere.
