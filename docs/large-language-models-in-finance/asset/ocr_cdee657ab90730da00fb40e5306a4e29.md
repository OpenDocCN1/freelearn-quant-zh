| Resource | Typical size | Primary task | Description |
| :--- | :--- | :--- | :--- |
| Financial PhraseBank | 4,840 sentences | Sentiment analysis | Financial-news sentence sentiment dataset annotated by finance-aware annotators. Use an explicit agreement split, such as `sentences_75agree`, `sentences_66agree`, or `sentences_50agree`, because the number of usable examples depends on the selected annotator-agreement threshold. |
| FiQA | Version-dependent | Financial opinion mining and question answering | Benchmark family associated with financial opinion mining and QA. FiQA-SA sentiment variants are commonly reported with approximately 1,173 annotated financial headlines or posts, while QA and RAG reformulations use different splits and sizes. Always report the exact benchmark version and split. |
| FinEAS model/code | Model/resource | Financial sentiment embeddings and sentiment analysis | FinEAS provides a supervised sentence-embedding approach for financial sentiment. It is useful as a specialized encoder or scoring module, but its label mapping, training distribution, temporal coverage, and production suitability must be validated before institutional use. |
| SEC EDGAR | Millions of filings | Document retrieval, extraction, and filing analysis | SEC EDGAR is a public filing database rather than a single curated NLP dataset. LLM workflows usually require filing selection, parsing, cleaning, metadata extraction, section segmentation, and task-specific labeling before modeling. |
| Earnings calls | Varies by vendor or source | Transcription analysis, sentiment, forecasting, and event analysis | Quarterly earnings-call transcripts can support management-tone analysis, question-answer analysis, guidance extraction, and market-reaction studies. Coverage and licensing depend on the provider. |
