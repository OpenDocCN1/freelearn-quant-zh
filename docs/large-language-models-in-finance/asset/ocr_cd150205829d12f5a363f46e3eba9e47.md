# 9.2.1 Theoretical framework

The standard mathematical framework for RL is a Markov decision process (MDP). An MDP describes a setting in which an agent observes a state, takes an action, receives a reward, and moves to a new state. In the context of LLMs, this can be represented by the tuple \(\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, R, \gamma, \rho_0)\) where:

+   - \(\mathcal{S}\): The state space, representing the current context including the input prompt and the sequence of tokens generated so far
+   - \(\mathcal{A}\): The action space, consisting of all possible tokens in the model's vocabulary \(V\), where \(|\mathcal{A}| = |V| \approx 50, 000 - 100, 000\)
+   - \(P : \mathcal{S} \times \mathcal{A} \times \mathcal{S} \to [0, 1]\): The transition probability function, which is typically deterministic once a token has been selected, because the chosen token is appended to the current context
+   - \(R : \mathcal{S} \times \mathcal{A} \to \mathbb{R}\): The reward function assigns a scalar signal to an action in a state. In financial settings, this signal may combine factual and numerical accuracy, risk awareness, regulatory compliance, and user preferences; the resulting scalarization must be validated because different components can conflict.
+   - \(\gamma \in [0, 1]\): The discount factor, balancing immediate and future rewards
+   - \(\rho_0\): The initial state distribution, typically the distribution over prompts

The LLM acts as the policy \(\pi_\theta(a|s)\), which is a probability distribution over the next token (action) given the current context (state), parameterized by the model's weights \(\theta\). The fundamental objective is to find the optimal policy \(\pi^*\) that maximizes the expected cumulative discounted reward:

```
\pi^* = \arg \max_\pi \mathbb{E}_{\tau \sim \pi} \left[ \sum_{t=0}^T \gamma^t R(s_t, a_t) \right] \tag{9.4}
```

where \(\tau = (s_0, a_0, s_1, a_1, ..., s_T, a_T)\) represents a trajectory (a complete generated sequence). In language generation, this trajectory can be understood as the sequence of token choices that produces a complete response.

Once the RL problem has been defined, the next question is how the model's policy is actually updated so that better responses become more likely.

# 9.2.2 Policy optimization in language space

The core challenge in RL for LLMs is updating the policy \(\pi_\theta\) to increase the probability of generating high-reward sequences. Policy gradient methods, particularly suited for the high-dimensional action spaces of language models, form the foundation of most approaches [Williams, 1992]. Policy gradient methods update the model by increasing the probability of actions that led to higher rewards and decreasing the probability of actions that led to lower rewards.
