It is worth being explicit about what this factor does *not* do, since the two are easily conflated. It has nothing to do with the magnitudes of the financial quantities in the text. A stock price of $4 and a trading volume of 40,000,000 are not reconciled by $1/\sqrt{d_k}$ — they are never seen as magnitudes by the attention mechanism at all, having been fragmented into subword tokens long before (Figure 2.2). Numerical scale is handled, to the extent it is handled, by the embedding and normalisation layers, and in practice by moving arithmetic out of the model entirely. Multi-head attention extends this mechanism by applying multiple attention functions in parallel, each with different learned linear projections of the queries, keys, and values:

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h)W^O
```

where each attention head is computed as:

```
head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
```

The projection matrices $W_i^Q \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^K \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^V \in \mathbb{R}^{d_{model} \times d_v}$, and $W^O \in \mathbb{R}^{h d_v \times d_{model}}$ are learned parameters that enable each head to attend to information from different representation subspaces.

Different attention heads often specialize in capturing distinct types of relationships in the finance context. Empirical analysis of financial transformer models has revealed that certain heads focus on syntactic relationships within financial documents, others on temporal dependencies in time series data, and still others on semantic relationships between financial concepts [Rogers et al., 2020]. This specialization enables a deep understanding of complex financial documents that contain mixed textual and numerical content. The feed-forward network within each transformer layer provides crucial non-linear transformations that enable complex pattern recognition.

The standard implementation uses two linear transformations with a ReLU activation:

```
FFN(x) = max(0, xW_1 + b_1)W_2 + b_2
```

However, recent financial model implementations have explored alternative activations, such as **Gaussian Error Linear Unit (GELU)** and Swish, which yield smoother gradients and improved convergence properties for financial data with continuous numerical distributions [Hendrycks and Gimpel, 2016].

Layer normalization and residual connections ensure stable gradient flow throughout deep networks, which is particularly crucial for financial models that may require dozens of layers to capture complex market dynamics:

```
z_l = LayerNorm(x_{l-1} + MultiHead(x_{l-1}))
```

```
x_l = LayerNorm(z_l + FFN(z_l))
```
