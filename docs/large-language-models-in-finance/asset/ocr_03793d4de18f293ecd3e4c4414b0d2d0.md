# 10.1.2 Cloud versus on-premises infrastructure

The cloud-versus-on-premises decision involves more than capital expenditure. Financial institutions must consider data classification, outsourcing risk, audit rights, jurisdiction, concentration risk, exit plans, encryption and key control, network predictability, skill availability, and expected utilization.
