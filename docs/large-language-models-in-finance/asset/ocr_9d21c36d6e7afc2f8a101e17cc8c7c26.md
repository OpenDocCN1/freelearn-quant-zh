# # Quantitative integration prompting

Financial analysis often requires sophisticated integration of quantitative models and statistical analysis. Quantitative integration prompting ensures appropriate use of mathematical and statistical techniques while maintaining analytical coherence.

Methodology-selection prompting guides the model toward suitable valuation frameworks:

> Select appropriate valuation methodology based on company characteristics: DCF for stable cash flow companies, relative valuation for cyclical industries, sum-of-the-parts for conglomerates, option-based models for early-stage growth companies. Justify methodology selection and provide sensitivity analysis.

Statistical validation prompting ensures proper application of statistical techniques:

> For correlation analysis, verify statistical significance (p-value <0.05), check for non-linear relationships, test for structural breaks, and provide confidence intervals. Address potential spurious correlations and ensure economic intuition supports statistical relationships.

Cross-validation prompting encourages verification of quantitative results through alternative approaches:

> Cross-validate DCF results using: (1) Comparable company analysis with appropriate multiples; (2) Precedent transaction analysis with control premiums; (3) Asset-based valuation for downside protection; (4) Economic value added (EVA) analysis for performance validation. Reconcile valuation differences and provide weighted average with confidence intervals.

# # Curriculum learning

Curriculum learning strategies present financial concepts in carefully designed sequences that mirror professional financial education and build complexity progressively. This approach often improves the convergence speed and final model performance for complex financial reasoning tasks.

Financial curriculum design typically follows hierarchical knowledge structures:

+   1. **Foundation phase**: Basic financial concepts, accounting principles, mathematical relationships
+   2. **Analytical phase**: Financial ratio analysis, comparative evaluation, trend analysis
+   3. **Integration phase**: Multi-factor analysis, cross-asset relationships, portfolio theory
+   4. **Advanced phase**: Complex derivatives, structured products, regulatory frameworks
+   5. **Application phase**: Real-world case studies, crisis scenarios, professional applications
