# # Applications of LLMs in Finance

This chapter explores concrete applications of Large Language Models (LLMs) across the front, middle, and back offices of financial institutions. Here, front office refers to revenue-generating functions such as trading, middle office covers risk and control functions, and back office covers operations and processing. Rather than treating models as isolated components, we view them as building blocks inside complete decision pipelines (full path from data intake to model processing, human review, action, and monitoring) for trading, risk management, banking operations, fraud detection, and regulatory compliance [Cao, 2022, Yang et al., 2020].

The focus is deliberately architectural. For each use case we describe:

+   - the **inputs** (data sources and their structure),
+   - the **processing pipeline** (models, RAG indices, agents, tools),
+   - the **outputs** (signals, scores, reports, alerts),
+   - and the **control layer** (limits, approvals, logs, monitoring).

We avoid performance claims or invented metrics; any real deployment must be validated on proprietary data under a rigorous model-risk framework [Danielsson et al., 2016].

Throughout this chapter, we reuse the *Financial LLM Stack* introduced earlier. This stack refers to the layers needed to build, connect, deploy, and govern LLM-based financial systems. In the stack below, *tool-context integration* is used as the generic architectural term: it includes Model Context Protocol (MCP)-style interfaces when an institution adopts MCP, but it also includes proprietary API gateways, internal service buses, workflow engines, and direct integrations with risk, order-management, compliance, and document systems.

*Data → Pretraining → Fine-tuning → RAG → Agents → Tool-context integration → RL / Alignment → Infrastructure → Governance → Frontier.*

Each section illustrates how different parts of this stack come together in production-grade workflows. We begin with the front office, where LLM applications are closest to investment decisions, market interpretation, and trading workflows.
