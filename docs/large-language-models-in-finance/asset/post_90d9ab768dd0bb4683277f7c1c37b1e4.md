### 2.1 Examining the Transformer architecture

The Transformer architecture represents the foundational shift that enabled the development of modern LLMs capable of sophisticated financial reasoning and analysis. The key contrast with earlier sequential architectures such as **recurrent neural networks (RNNs)** and **long short-term memory networks (LSTMs)** is not that RNNs and LSTMs are incapable of modeling non-linear relationships. They can. The decisive difference is that transformers process sequences in parallel through self-attention and allow direct interaction between distant tokens, which improves computational efficiency and strengthens the modeling of long-range dependencies that are critical in financial applications [Vaswani et al., 2017].

The impact of transformers on financial AI stems from their ability to connect disparate financial concepts, entities, and temporal patterns within long documents and data streams. In a sequential model, information about an early covenant, risk disclosure, or macroeconomic event must propagate through many recurrent steps before it affects a later representation. In a transformer, the attention mechanism can directly relate that earlier token or passage to a later one, regardless of distance. This is especially valuable in finance, where a current valuation, risk assessment, or compliance conclusion may depend on information disclosed many pages or many reporting periods earlier.

### 2.1.1 Transformer layers

The transformer architecture consists of encoder and decoder stacks, each containing multiple identical layers. For financial applications, both encoder-only models (like BERT and its financial variants such as FinBERT) and decoder-only models (like GPT and BloombergGPT) have proven effective, with the choice depending on the specific financial task requirements [Devlin et al., 2019, Yang et al., 2020, Wu et al., 2023b]. For example, an encoder-only model such as FinBERT is well-suited to tasks like sentiment classification of earnings-call transcripts or financial news, where the objective is to assign a label to an input text, whereas a decoder-only model such as BloombergGPT is more appropriate for tasks like generating market commentary, drafting financial reports, or answering investor queries, where the goal is to produce coherent text conditioned on prior context [Yang et al., 2020, Wu et al., 2023b].

Each transformer layer is built around the attention mechanism, which allows every token in a sequence to directly reference every other token when constructing its representation. This replaces the sequential processing used in recurrent models and enables efficient modeling of long-range dependencies. Mathematically, each transformer layer implements a sophisticated attention mechanism that can be mathematically decomposed into three primary operations: query, key, and value transformations. The self-attention mechanism computes attention weights by measuring the compatibility between queries and keys, then uses these weights to aggregate value vectors. This process can be formalized as follows:

Attention(Q, K, V) = softmax \left( \frac{QK^T}{\sqrt{d_k}} \right) V (2.1)

where, Q \in \mathbb{R}^{n \times d_k}, K \in \mathbb{R}^{n \times d_k}, \text{and } V \in \mathbb{R}^{n \times d_v} \text{ represent the query, key, and value matrices, respectively, with } n \text{ being the sequence length and } d_k, d_v \text{ the respective dimensions.}

Intuitively, each query vector asks, "what kind of information is this looking for?", while each key vector announces, "what kind of information does this token contain?" The dot product QK^T measures the compatibility between these two roles. A large query-key dot product means that one token should pay strong attention to another token. The value vectors then carry the information that is actually aggregated. In a financial sense, for example, the token "margin" may attend strongly to "compressed", "Q3", and "energy costs" because those tokens jointly explain the economic meaning of the margin change.

The scaling factor \frac{1}{\sqrt{d_k}} prevents the softmax from saturating when d_k is large. The reason is purely dimensional and is worth stating exactly, because it is often mis-explained. If the components of q and k are independent with mean zero and unit variance, then q \cdot k has variance d_k; the logits therefore grow with the key dimension. Large logits drive the softmax towards a one-hot distribution, and a near-one-hot softmax has vanishingly small gradients with respect to its inputs — the model saturates on a single key and stops learning to weigh alternatives. Dividing by \sqrt{d_k} restores unit variance and keeps the distribution soft enough to carry gradient.

It is worth being explicit about what this factor does *not* do, since the two are easily conflated. It has nothing to do with the magnitudes of the financial quantities in the text. A stock price of $4 and a trading volume of 40,000,000 are not reconciled by $1/\sqrt{d_k}$ — they are never seen as magnitudes by the attention mechanism at all, having been fragmented into subword tokens long before (Figure 2.2). Numerical scale is handled, to the extent it is handled, by the embedding and normalisation layers, and in practice by moving arithmetic out of the model entirely. Multi-head attention extends this mechanism by applying multiple attention functions in parallel, each with different learned linear projections of the queries, keys, and values:

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h)W^O
```

where each attention head is computed as:

```
head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
```

The projection matrices $W_i^Q \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^K \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^V \in \mathbb{R}^{d_{model} \times d_v}$, and $W^O \in \mathbb{R}^{h d_v \times d_{model}}$ are learned parameters that enable each head to attend to information from different representation subspaces.

Different attention heads often specialize in capturing distinct types of relationships in the finance context. Empirical analysis of financial transformer models has revealed that certain heads focus on syntactic relationships within financial documents, others on temporal dependencies in time series data, and still others on semantic relationships between financial concepts [Rogers et al., 2020]. This specialization enables a deep understanding of complex financial documents that contain mixed textual and numerical content. The feed-forward network within each transformer layer provides crucial non-linear transformations that enable complex pattern recognition.

The standard implementation uses two linear transformations with a ReLU activation:

```
FFN(x) = max(0, xW_1 + b_1)W_2 + b_2
```

However, recent financial model implementations have explored alternative activations, such as **Gaussian Error Linear Unit (GELU)** and Swish, which yield smoother gradients and improved convergence properties for financial data with continuous numerical distributions [Hendrycks and Gimpel, 2016].

Layer normalization and residual connections ensure stable gradient flow throughout deep networks, which is particularly crucial for financial models that may require dozens of layers to capture complex market dynamics:

```
z_l = LayerNorm(x_{l-1} + MultiHead(x_{l-1}))
```

```
x_l = LayerNorm(z_l + FFN(z_l))
```
