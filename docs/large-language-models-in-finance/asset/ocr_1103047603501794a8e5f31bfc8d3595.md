Step 10: Add a human review workflow and deployment modes A minimal prototype may simply return the final memo to the user. A deployable workflow should instead return a review packet. The reviewer should see the memo, the material claims, the evidence behind each claim, the computed metrics, and the risk annotations in one place. This encourages review of the reasoning path rather than passive acceptance of the final prose.

class ReviewPacket:
