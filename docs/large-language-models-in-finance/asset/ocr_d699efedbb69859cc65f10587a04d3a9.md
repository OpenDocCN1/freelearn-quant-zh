**Proposition 4.3.1** (Time-valid RAG prevents direct corpus lookahead). *Assume the index at decision time t is built only from* \(\mathcal{D}_t\)*, the retriever returns only elements of that index, and the generator prompt is a deterministic function of the query, the retrieved evidence, approved policy text, and model configuration available at t. Then the generated answer cannot directly condition on documents with availability time greater than t through the retrieval channel.*

*Proof.* The retriever's codomain is \(\mathcal{D}_t^k\), so every retrieved item has availability time at most \( t \). The prompt is a deterministic function of the query, retrieved items, approved policy text, and configuration available at \( t \). Therefore the retrieval-augmented context is measurable with respect to the information available at time \( t \). The proposition concerns the retrieval channel only; it does not eliminate all possible contamination from model pre-training, vendor backfills, prompt examples, or external tools. Those channels require separate controls. \(\square\)

In production, the proposition is implemented by three simple rules: index versions must have timestamps, retrieval logs must record document IDs and availability times, and the generation step must refuse to run if any retrieved artifact violates the decision timestamp. The reference code in the companion repository implements this rule with typed evidence objects and an explicit availability-time check.

A standard auto-regressive language model generates a response \( y = (y_1, \dots, y_T) \) according to:

\[ p(y \mid q) = \prod_{t=1}^T p(y_t \mid y_{<t}, q; \theta) \] (4.1)

where \(\theta\) represents the model parameters and \( y_{<t} = (y_1, \dots, y_{t-1}) \) denotes the previously generated tokens.

RAG, on the other hand, augments generation by marginalizing over retrieved documents:

\[ p(y \mid q) = \sum_{d \in \mathcal{D}} p(y \mid q, d; \theta) \cdot p(d \mid q) \] (4.2)

where \( p(d \mid q) \) represents the relevance distribution over documents.

In practice, we approximate this marginalization by retrieving the top-\( k \) documents:

\[ p(y \mid q) \approx \prod_{t=1}^T p(y_t \mid y_{<t}, q, d_1, \dots, d_k; \theta) \] (4.3)
